Ping Alerts

Sound and notification delivery are independent for each Ping event. The master switch above controls audio only; notifications also require Show alert notifications on the target. Custom MP3/WAV files are limited to 2 MiB each, 12 MiB total, and 10 seconds maximum duration. If sound is enabled and no custom file is provided, Target Monitor uses a built-in beep.

Monitoring Engine

Sampling intervals

Ping, TCP, and HTTP run on independent schedules. Slower HTTP requests do not delay Ping or TCP sampling.

History

History windows are time-based, so they remain accurate even when probe types use different sampling intervals.
